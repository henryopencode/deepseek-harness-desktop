# `@deepseek-ai/dsh-client-ui-runtime-update`

[English](README.md) | 中文

受管 Web 运行时的更新提示。插件在页面 shell 挂载后检查 Host 的发布源，并在页面保持打开时每五分钟重新检查；没有更新配置或网络不可用时保持隐藏。发现更新时显示双语对话框；回环运行时以及声明了 `installAvailable` 的远程部署可选择“稍后”或“立即更新”。选择“稍后”会在当前页面内忽略该版本，发现更晚的版本时仍会再次显示对话框。

安装操作需要用户确认，并防止重复点击。Host 启动经过校验的更新器，停止并重启受管服务。浏览器容忍重启期间的连接中断，持续调用 `host.describe` 确认目标版本响应后才刷新页面。检查失败保持静默；安装失败会留在对话框中并允许重试。

## 模型体验

无，因为浏览器 UI 只检查和控制 Host 运行时生命周期，不增加模型可见输入、工具输出或会话事件。

#### KV Cache 影响

无；本插件不组装也不发送 provider 请求。

## 已知限制与延期工作

- 发布源使用 GitHub Releases，并要求运行时提供更新配置。
- 远程部署在反向代理完成鉴权后可以收到更新状态；只有 Host 部署开启 `allowRemoteUpdate` 并在 `trustedHosts` 中声明服务权威时，页面才提供安装操作。
- 浏览器等待时间有上限；服务重启超过上限时需要手动刷新页面。
