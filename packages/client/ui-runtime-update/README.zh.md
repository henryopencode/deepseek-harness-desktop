# `@deepseek-ai/dsh-client-ui-runtime-update`

[English](README.md) | 中文

受管 Web 运行时的更新提示。插件在页面 shell 挂载后检查 Host 的发布源，并在页面保持打开时每五分钟重新检查；没有更新配置或网络不可用时保持隐藏。发现更新时显示双语对话框；回环运行时以及声明了 `installAvailable` 的远程部署可选择“稍后”或“立即更新”。选择“稍后”会在当前页面内忽略该版本，发现更晚的版本时仍会再次显示对话框。

安装操作需要用户确认，并防止重复点击。Host 启动经过校验的更新器；更新器在下载和校验归档、按需安装 JavaScript 依赖和本地 Whisper CLI、停止并重启受管服务的过程中，会把阶段、百分比、当前安装步骤和步骤开始时间写入运行时自己的进度文件。浏览器通过 `host.updateStatus` 读取状态，在有上限的安装窗口内显示当前步骤和已用时；当读取到与目标版本匹配的 `completed` 记录时即视为更新成功，并保留完成状态和“重启服务”按钮。点击按钮会刷新页面并重新连接新运行时；即使浏览器没有自动刷新，也不会一直停留在“正在更新”。服务重连期间再用 `host.describe` 作为备用就绪检查。检查失败保持静默；安装失败会在对话框中显示诊断并允许重试。更新器网络请求默认超时五分钟；部署可以在 `update-config.json` 设置 `networkTimeoutMs`，或通过 `DSH_UPDATE_NETWORK_TIMEOUT_MS` 覆盖。

## 模型体验

无，因为浏览器 UI 只检查和控制 Host 运行时生命周期，不增加模型可见输入、工具输出或会话事件。

#### KV Cache 影响

无；本插件不组装也不发送 provider 请求。

## 已知限制与延期工作

- 发布源使用 GitHub Releases，并要求运行时提供更新配置。
- 远程部署在反向代理完成鉴权后可以收到更新状态；只有 Host 部署开启 `allowRemoteUpdate` 并在 `trustedHosts` 中声明服务权威时，页面才提供安装操作。
- 浏览器等待安装和重启的时间最多十分钟；更慢的安装可能仍在后台继续，可手动刷新页面检查。
