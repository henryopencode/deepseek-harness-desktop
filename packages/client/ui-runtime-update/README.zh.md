# `@deepseek-ai/dsh-client-ui-runtime-update`

[English](README.md) | 中文

受管 Web 运行时的本地更新提示。插件在页面 shell 挂载后检查 Host 的发布源；没有更新配置、网络不可用或通过非本机地址访问时保持隐藏。发现更新时显示双语对话框，由用户明确选择“稍后”或“立即更新”。

安装操作需要用户确认，并防止重复点击。Host 启动经过校验的更新器，停止并重启受管服务。浏览器容忍重启期间的连接中断，持续调用 `host.describe` 确认目标版本响应后才刷新页面。检查失败保持静默；安装失败会留在对话框中并允许重试。

## 模型体验

无。本功能只控制 Host 生命周期，不增加模型可见输入、工具输出或会话事件。

## 已知限制

- 发布源使用 GitHub Releases，并要求运行时提供更新配置。
- 浏览器等待时间有上限；服务重启超过上限时需要手动刷新页面。
